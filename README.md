# NK Gabru Photography — Indian Wedding Frontend

A React + JavaScript + Vite frontend concept focused on Indian wedding photography and cinematic films.

## Run locally

1. Extract this folder.
2. Open the folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Included

- Indian wedding-inspired maroon, gold and cinematic dark palette
- Real photographer-shot wedding stock photos loaded from Pexels/Unsplash (internet required for demo imagery)
- Responsive navigation and layout
- Animated hero, hover effects, scroll reveals
- Portfolio category filters and image lightbox
- Service cards, cinematic films section, story, testimonials and contact-form demo

## Before delivering to the client

- Replace sample photos with NK Gabru Photography's real, approved wedding photographs and film stills.
- Replace placeholder testimonials and stats with verified business details.
- Update contact details and Instagram URL.
- The enquiry form is frontend-only and does not send or store enquiries yet.


## Photography images

The demo now uses real photographer-shot stock photos from Pexels (and one existing Unsplash image) rather than AI-generated wedding artwork. Internet access is required to load these remote demo images. Before the site is delivered to the client, replace all stock photos with NK Gabru Photography's own approved wedding photographs and confirm usage rights for any third-party images.

The homepage hero rotates through wedding photographs every 6.5 seconds. Scroll reveals use IntersectionObserver; portfolio and service images have hover zoom/slide transitions.
